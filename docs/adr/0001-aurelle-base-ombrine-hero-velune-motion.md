# AURELLE هو الأساس، Ombrine للهيرو بس، VÉLUNE للحركة بس

المشروع بدأ على مرجع VÉLUNE (أسود، فساتين سهرة)، وفي 2026-10-14 اتحوّل لـ AURELLE (كريمي، quiet luxury، متجر مكتمل تجارياً، منتجاته بتتطابق مع إطلالات هيرو Ombrine). بناخد من كل مرجع حاجة واحدة بس: AURELLE = الهوية والأقسام، Ombrine = فكرة الـ Salon، VÉLUNE = سلوك ظهور النص حرف حرف والـ parallax — وكلهم بيترسموا بخطوط وألوان AURELLE عشان الموقع يفضل ستايل واحد مش ترقيع من 3 قوالب.
